features_h = 功能
f_chat = <strong>聊天。</strong>与一个或多个角色交谈，他们轮流发言，或彼此继续聊下去。可以回到任意一条消息，换一条路走。
f_cards = <strong>角色卡。</strong>从零开始创建角色，或在与 AI 的对话中创建，并在角色自己的页面上编辑。
f_library = <strong>角色库。</strong>按名字、标签或内容找到角色。AI 会为你的角色卡加标签并写摘要。
f_memory = <strong>记忆。</strong>角色记得发生过的事，并能参考你给它们的文档。
f_companion = <strong>伙伴。</strong>桌面上的 3D 形象，和你聊天、朗读自己的回复、陪伴你，也能当日常助手。
f_voices = <strong>语音。</strong>在你的电脑上用每个角色自己的声音朗读回复。可以用语音输入代替打字。
f_pictures = <strong>图片。</strong>在聊天中生成图片。
f_tools = <strong>工具。</strong>让模型搜索网页、在一个文件夹里工作或运行命令，每一项都只在你允许时进行。
f_coding = <strong>编程团队。</strong>给它一个目标和一个文件夹，一组 AI 智能体就会替你完成工作。
f_local = <strong>本地模型。</strong>在你自己的电脑上运行模型，无需密钥和账号。
f_tabs = <strong>标签页和主题。</strong>在标签页中同时打开多个聊天和角色卡。浅色、深色或另外五种主题之一。
f_locked = <strong>上锁和备份。</strong>用密码锁住应用；备份就是一个文件。
f_devices = <strong>手机和其他电脑。</strong>在家庭网络中的手机或其他电脑上，用浏览器打开 Cardwave。尚处早期阶段，还未经过充分测试。
f_language = <strong>你的语言。</strong>Cardwave 支持十二种语言。
privacy_h = 隐私
privacy_p = Cardwave 把角色卡、聊天、密钥和设置保存在你电脑上的加密数据库中。无需注册，没有同步，应用内没有分析统计。它只在你要求时联网：发给你填写了 API 密钥的服务商的消息、你启动的下载（搜索模型、语音）、你开启的网页工具，以及在 GitHub 上检查新版本（可在设置中关闭）。
byo_h = 使用你自己的 AI
byo_p1 = 用你已经在用的 AI。粘贴一个 API 密钥，Cardwave 就知道它属于谁：OpenAI、Anthropic、Google、xAI、Mistral、DeepSeek、OpenRouter、NanoGPT，以及<a href="{providers}">其他 150 多家</a>。任何兼容 OpenAI 的服务器也可以，按地址连接。
byo_p2 = 也可以在你自己的电脑上运行模型：把 Cardwave 指向一个存放 GGUF 文件的文件夹，它会自己运行这些模型，能用显卡时就用显卡。
providers_h = 支持的服务商
providers_p = 查看 <a href="{providers}">Cardwave 支持的 AI 服务商列表</a>，每家都附有其网站链接。
cards_h = 角色卡
cards_p = Cardwave 可以通过“创建”或拖放到资料库来导入 SillyTavern PNG 角色卡和 CCV4 角色卡。角色卡可导出为 SillyTavern V3 或 CCV4，聊天可导出为 SillyTavern 的聊天格式。
where_h = 去哪里找角色
where_p = Cardwave 能打开来自任何地方的角色卡。查看<a href="{where}">提供角色卡的网站列表</a>，下载后导入 Cardwave 即可。
costs_h = 费用估算
costs_p = 聊天费用会随对话变长而增加，因为每一轮都会重新发送历史记录。<a href="{calculator}">聊天轮次预算计算器</a>可按任意模型的每 token 价格，估算一笔预算能聊多少轮。
roleplay_h = 热门角色扮演模型
roleplay_p = 查看<a href="{roleplay}">角色扮演中最常用的模型</a>，数据来自 OpenRouter 的排行榜，每周更新，并附上每个模型的每 token 价格。
scope_h = 项目范围
scope_p = Cardwave 免费，由一个人开发，按现状发布。
beta_h = 测试版
beta_p = Cardwave 正在积极开发中，这是它的第一个公开版本。更新后可能无法保留旧版本保存的内容，所以请导出你在意的角色卡并保留备份。问题和建议请提交到 <a href="{issues}" target="_blank" rel="noopener noreferrer">GitHub Issues</a>。
ccv4_h = CCV4 卡片格式
ccv4_p = CCV4 是一个草案阶段的角色卡格式，由 TOML 编写的小型可寻址文本块组成，存储在 PNG 数据块中。阅读 <a href="{ccv4}">CCV4 概览</a>，包含完整规范、提示词组装算法、参考示例和在线演练场。
