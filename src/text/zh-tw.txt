features_h = 功能
f_chat = <strong>聊天。</strong>與一個或多個角色交談，他們輪流發言，或彼此繼續聊下去。可以回到任何一則訊息，換一條路走。
f_cards = <strong>角色卡。</strong>從零開始建立角色，或在與 AI 的對話中建立，並在角色自己的頁面上編輯。
f_library = <strong>角色庫。</strong>依名字、標籤或內容找到角色。AI 會為你的角色卡加上標籤並撰寫摘要。
f_memory = <strong>記憶。</strong>角色記得發生過的事，並能參考你給它們的文件。
f_companion = <strong>夥伴。</strong>桌面上的 3D 形象，和你聊天、朗讀自己的回覆、陪伴你，也能當日常助理。
f_voices = <strong>語音。</strong>在你的電腦上用每個角色自己的聲音朗讀回覆。可以用語音輸入代替打字。
f_pictures = <strong>圖片。</strong>在聊天中產生圖片。
f_tools = <strong>工具。</strong>讓模型搜尋網路、在一個資料夾裡工作或執行指令，每一項都只在你允許時進行。
f_coding = <strong>程式團隊。</strong>給它一個目標和一個資料夾，一組 AI 代理就會替你完成工作。
f_local = <strong>本機模型。</strong>在你自己的電腦上執行模型，不需要金鑰和帳號。
f_tabs = <strong>分頁和主題。</strong>在分頁中同時開啟多個聊天和角色卡。淺色、深色或另外五種主題之一。
f_locked = <strong>上鎖和備份。</strong>用密碼鎖住應用程式；備份就是一個檔案。
f_language = <strong>你的語言。</strong>Cardwave 支援十二種語言。
privacy_h = 隱私
privacy_p = Cardwave 把角色卡、聊天、金鑰和設定儲存在你電腦上的加密資料庫中。無需註冊，沒有同步，應用程式內沒有分析統計。它只在你要求時連網：傳給你填寫了 API 金鑰的服務商的訊息、你啟動的下載（搜尋模型、語音）、你開啟的網頁工具，以及在 GitHub 上檢查新版本（可在設定中關閉）。
byo_h = 使用你自己的 AI
byo_p1 = 用你已經在用的 AI。貼上一個 API 金鑰，Cardwave 就知道它屬於誰：OpenAI、Anthropic、Google、xAI、Mistral、DeepSeek、OpenRouter、NanoGPT，以及<a href="{providers}">其他 150 多家</a>。任何相容 OpenAI 的伺服器也可以，依位址連線。
byo_p2 = 也可以在你自己的電腦上執行模型：把 Cardwave 指向一個存放 GGUF 檔案的資料夾，它會自己執行這些模型，能用顯示卡時就用顯示卡。
providers_h = 支援的服務商
providers_p = 查看 <a href="{providers}">Cardwave 支援的 AI 服務商清單</a>，每家都附有其網站連結。
cards_h = 角色卡
cards_p = Cardwave 可以透過「建立」或拖放到資料庫來匯入 SillyTavern PNG 角色卡和 CCV4 角色卡。角色卡可匯出為 SillyTavern V3 或 CCV4，聊天可匯出為 SillyTavern 的聊天格式。
where_h = 去哪裡找角色
where_p = Cardwave 能開啟來自任何地方的角色卡。查看<a href="{where}">提供角色卡的網站清單</a>，下載後匯入 Cardwave 即可。
costs_h = 費用估算
costs_p = 聊天費用會隨對話變長而增加，因為每一輪都會重新傳送歷史紀錄。<a href="{calculator}">聊天輪次預算計算機</a>可按任何模型的每 token 價格，估算一筆預算能聊多少輪。
scope_h = 專案範圍
scope_p = Cardwave 免費，由一個人開發，按現狀發佈。
beta_h = 測試版
beta_p = Cardwave 正在積極開發中，這是它的第一個公開版本。更新後可能無法保留舊版本儲存的內容，所以請匯出你在意的角色卡並保留備份。問題和建議請提交到 <a href="{issues}" target="_blank" rel="noopener noreferrer">GitHub Issues</a>。
ccv4_h = CCV4 卡片格式
ccv4_p = CCV4 是草案階段的角色卡格式，由 TOML 撰寫的小型可定址文字區塊組成，儲存在 PNG 區塊中。閱讀 <a href="{ccv4}">CCV4 總覽</a>，內含完整規範、提示詞組裝演算法、參考範例與線上遊樂場。
