Cardwave

适用于 Windows 和 Linux 的 AI 角色聊天应用与角色卡编辑器。接入你已在使用的任意 AI 服务商。你的角色卡、聊天和密钥都留在你的电脑上。

功能

  • 角色卡。自己写角色、生成一个，或与 AI 一起创作。
  • 按需求。选出你需要的，看看哪些角色能提供。
  • 记忆。角色记得你们聊天中发生过的事。
  • 伙伴。桌面上会和你聊天的 3D 形象。
  • 版本。角色卡的每段文字都保留之前的版本。
  • 翻译。把角色卡译成另一种语言，左右对照。
  • 语音。用每个角色自己的声音朗读回复。
  • 自制工具。AI 在沙盒中为自己编写小工具。

隐私

角色卡、聊天、密钥和设置都保存在你电脑上的加密数据库中。无需注册，没有同步，应用内没有分析统计。

使用你自己的 AI

粘贴一个 API 密钥，Cardwave 就能认出它属于谁：OpenAI、Anthropic、Google、xAI、Mistral、DeepSeek、OpenRouter、NanoGPT，以及另外 150 多家。任何兼容 OpenAI 的服务器也能用。

也可以在你自己的电脑上运行模型。把 Cardwave 指向一个存放 GGUF 文件的文件夹，它会尽量用你的显卡运行。

支持的服务商

查看 Cardwave 支持的 AI 服务商列表，每家都附有其网站链接。

角色卡

Cardwave 可导入 SillyTavern PNG 角色卡和 CCV4 角色卡。角色卡可导出为 SillyTavern V3 或 CCV4，聊天可导出为 SillyTavern 格式。
