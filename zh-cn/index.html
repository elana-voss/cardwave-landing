Cardwave

适用于 Windows 的 AI 角色聊天应用与角色卡编辑器。接入你已在使用的任意 AI 服务商。你的角色卡、聊天和密钥都留在你的电脑上。

功能

  • 与角色聊天。 回复边写边显示。可以重新生成、编辑、保留每个版本，并从任意消息开出分支。把多个角色拉进同一个聊天：他们轮流发言，或彼此一直聊下去。
  • 创建和编辑角色卡。 角色卡的页面就是它的编辑器，每段文本都保留之前的草稿。可以从零写一张卡，也可以回答 AI 的问题，让它和你一起写出角色。
  • 好找的资料库。 按文字和按含义搜索，搜索模型在你的电脑上运行。AI 为每张卡写标签、一句话简介和摘要。人设和世界书就在你的角色旁边。
  • 记忆。 每 20 条消息，AI 会记下聊天中的事实和事件，角色在回复前会想起自己知道的事。可以给聊天或角色提供文档作为参考。
  • 语音和图片。 消息在你的电脑上朗读，每个角色用自己的声音，或用一段录音制作的声音。在聊天中用服务商的图像模型或 ComfyUI 生成图片。
  • 工具。 让模型搜索网页、处理某个文件夹中的文件，或在沙盒中运行命令，每一项都只在你允许时进行。一个编程团队可以替你在文件夹里朝一个目标工作。
  • 加锁与备份。 密码可以锁住应用。备份是一个加锁的文件，可以在这台或另一台电脑上恢复。
  • 你的语言。 Cardwave 支持 12 种语言，并有浅色和深色两种主题。

隐私

Cardwave 把角色卡、聊天、密钥和设置保存在你的电脑上。无需注册，没有同步，应用内没有分析统计。它只在你要求时联网：发给你填写了 API 密钥的服务商的消息、你启动的下载（搜索模型、语音）、你开启的网页工具，以及在 GitHub 上检查新版本（可在设置中关闭）。中间没有任何 Cardwave 服务器。

模型

Cardwave 使用 API 密钥直接与服务商通信。粘贴密钥后，Cardwave 会识别它属于哪家服务商，再帮你选择聊天模型，以及一个更便宜的模型来做它自己的后台工作。从下面选择一个服务商，或添加你自己的。可以把多套设置保存为预设并随时切换。Cardwave 没有订阅。

  • platform.openai.com GPT- OpenAI
  • console.anthropic.com Claude - Anthropic
  • aistudio.google.com Gemini- Google
  • console.x.ai Grok - xAI
  • openrouter.ai OpenRouter- 多种模型
  • nano-gpt.com NanoGPT - 多种模型

使用其他服务？手动添加即可。输入地址，将 Cardwave 指向任何兼容 OpenAI 的服务器，包括你自己机器上的本地模型。Cardwave 会获取其模型列表，或者你自己输入模型。本地服务器无需 API 密钥。

角色卡

Cardwave 可以通过“创建”或拖放到资料库来导入 SillyTavern PNG 角色卡和 CCV4 角色卡。角色卡可导出为 SillyTavern V3 或 CCV4，聊天可导出为 SillyTavern 的聊天格式。

去哪里找角色

Cardwave 能打开来自任何地方的角色卡。查看提供角色卡的网站列表，下载后导入 Cardwave 即可。

费用估算

聊天费用会随对话变长而增加，因为每一轮都会重新发送历史记录。聊天轮次预算计算器可按任意模型的每 token 价格，估算一笔预算能聊多少轮。

CCV4 卡片格式

CCV4 是一个草案阶段的角色卡格式，由 TOML 编写的小型可寻址文本块组成，存储在 PNG 数据块中。阅读 CCV4 概览，包含完整规范、提示词组装算法、参考示例和在线演练场。
