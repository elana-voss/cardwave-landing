Cardwave

適用於 Windows 的 AI 角色聊天應用程式與角色卡編輯器。接入你已在使用的任何 AI 服務商。你的角色卡、聊天和金鑰都留在你的電腦上。

功能

  • 與角色聊天。 回覆邊寫邊顯示。可以重新產生、編輯、保留每個版本，並從任何訊息開出分支。把多個角色拉進同一個聊天：他們輪流發言，或彼此一直聊下去。
  • 建立和編輯角色卡。 角色卡的頁面就是它的編輯器，每段文字都保留先前的草稿。可以從零寫一張卡，也可以回答 AI 的問題，讓它和你一起寫出角色。
  • 好找的資料庫。 依文字和依含義搜尋，搜尋模型在你的電腦上執行。AI 為每張卡寫標籤、一句話簡介和摘要。使用者角色和世界書就在你的角色旁邊。
  • 記憶。 每 20 則訊息，AI 會記下聊天中的事實和事件，角色在回覆前會想起自己知道的事。可以給聊天或角色提供文件作為參考。
  • 語音和圖片。 訊息在你的電腦上朗讀，每個角色用自己的聲音，或用一段錄音製作的聲音。在聊天中用服務商的圖像模型或 ComfyUI 產生圖片。
  • 工具。 讓模型搜尋網頁、處理某個資料夾中的檔案，或在沙箱中執行指令，每一項都只在你允許時進行。一個程式設計團隊可以替你在資料夾裡朝一個目標工作。
  • 加鎖與備份。 密碼可以鎖住應用程式。備份是一個加鎖的檔案，可以在這台或另一台電腦上還原。
  • 你的語言。 Cardwave 支援 12 種語言，並有淺色和深色兩種主題。

隱私

Cardwave 把角色卡、聊天、金鑰和設定儲存在你的電腦上。無需註冊，沒有同步，應用程式內沒有分析統計。它只在你要求時連網：傳給你填寫了 API 金鑰的服務商的訊息、你啟動的下載（搜尋模型、語音）、你開啟的網頁工具，以及在 GitHub 上檢查新版本（可在設定中關閉）。中間沒有任何 Cardwave 伺服器。

模型

Cardwave 使用 API 金鑰直接與服務商通訊。貼上金鑰後，Cardwave 會辨識它屬於哪家服務商，再幫你選擇聊天模型，以及一個更便宜的模型來做它自己的背景工作。從下面選擇一個服務商，或新增你自己的。可以把多套設定儲存為預設並隨時切換。Cardwave 沒有訂閱。

  • platform.openai.com GPT- OpenAI
  • console.anthropic.com Claude - Anthropic
  • aistudio.google.com Gemini- Google
  • console.x.ai Grok - xAI
  • openrouter.ai OpenRouter- 多種模型
  • nano-gpt.com NanoGPT - 多種模型

使用其他服務？手動新增即可。輸入位址，將 Cardwave 指向任何相容 OpenAI 的伺服器，包括你自己機器上的本機模型。Cardwave 會取得其模型清單，或者你自己輸入模型。本機伺服器無需 API 金鑰。

角色卡

Cardwave 可以透過「建立」或拖放到資料庫來匯入 SillyTavern PNG 角色卡和 CCV4 角色卡。角色卡可匯出為 SillyTavern V3 或 CCV4，聊天可匯出為 SillyTavern 的聊天格式。

去哪裡找角色

Cardwave 能開啟來自任何地方的角色卡。查看提供角色卡的網站清單，下載後匯入 Cardwave 即可。

費用估算

聊天費用會隨對話變長而增加，因為每一輪都會重新傳送歷史紀錄。聊天輪次預算計算機可按任何模型的每 token 價格，估算一筆預算能聊多少輪。

CCV4 卡片格式

CCV4 是草案階段的角色卡格式，由 TOML 撰寫的小型可定址文字區塊組成，儲存在 PNG 區塊中。閱讀 CCV4 總覽，內含完整規範、提示詞組裝演算法、參考範例與線上遊樂場。
