Cardwave

適用於 Windows 的 AI 角色聊天應用程式與角色卡編輯器。接入你已在使用的任何 AI 服務商。你的角色卡、聊天和金鑰都留在你的電腦上。

功能

  • 聊天。與一個或多個角色交談，他們輪流發言，或彼此繼續聊下去。可以回到任何一則訊息，換一條路走。
  • 角色卡。從零開始建立角色，或在與 AI 的對話中建立，並在角色自己的頁面上編輯。
  • 角色庫。依名字、標籤或內容找到角色。AI 會為你的角色卡加上標籤並撰寫摘要。
  • 記憶。角色記得發生過的事，並能參考你給它們的文件。
  • 夥伴。桌面上的 3D 形象，和你聊天、朗讀自己的回覆、陪伴你，也能當日常助理。
  • 語音。在你的電腦上用每個角色自己的聲音朗讀回覆。可以用語音輸入代替打字。
  • 圖片。在聊天中產生圖片。
  • 工具。讓模型搜尋網路、在一個資料夾裡工作或執行指令，每一項都只在你允許時進行。
  • 程式團隊。給它一個目標和一個資料夾，一組 AI 代理就會替你完成工作。
  • 本機模型。在你自己的電腦上執行模型，不需要金鑰和帳號。
  • 分頁和主題。在分頁中同時開啟多個聊天和角色卡。淺色、深色或另外五種主題之一。
  • 上鎖和備份。用密碼鎖住應用程式；備份就是一個檔案。
  • 手機和其他電腦。在家用網路中的手機或其他電腦上，用瀏覽器開啟 Cardwave。仍在早期階段，尚未經過充分測試。
  • 你的語言。Cardwave 支援十二種語言。

隱私

Cardwave 把角色卡、聊天、金鑰和設定儲存在你電腦上的加密資料庫中。無需註冊，沒有同步，應用程式內沒有分析統計。它只在你要求時連網：傳給你填寫了 API 金鑰的服務商的訊息、你啟動的下載（搜尋模型、語音）、你開啟的網頁工具，以及在 GitHub 上檢查新版本（可在設定中關閉）。

使用你自己的 AI

用你已經在用的 AI。貼上一個 API 金鑰，Cardwave 就知道它屬於誰：OpenAI、Anthropic、Google、xAI、Mistral、DeepSeek、OpenRouter、NanoGPT，以及其他 150 多家。任何相容 OpenAI 的伺服器也可以，依位址連線。

也可以在你自己的電腦上執行模型：把 Cardwave 指向一個存放 GGUF 檔案的資料夾，它會自己執行這些模型，能用顯示卡時就用顯示卡。

支援的服務商

查看 Cardwave 支援的 AI 服務商清單，每家都附有其網站連結。

角色卡

Cardwave 可以透過「建立」或拖放到資料庫來匯入 SillyTavern PNG 角色卡和 CCV4 角色卡。角色卡可匯出為 SillyTavern V3 或 CCV4，聊天可匯出為 SillyTavern 的聊天格式。

去哪裡找角色

Cardwave 能開啟來自任何地方的角色卡。查看提供角色卡的網站清單，下載後匯入 Cardwave 即可。

費用估算

聊天費用會隨對話變長而增加，因為每一輪都會重新傳送歷史紀錄。聊天輪次預算計算機可按任何模型的每 token 價格，估算一筆預算能聊多少輪。

熱門角色扮演模型

查看角色扮演中最常用的模型，資料來自 OpenRouter 的排行榜，每週更新，並附上每個模型的每 token 價格。

測試版

Cardwave 正在積極開發中，這是它的第一個公開版本。更新後可能無法保留舊版本儲存的內容，所以請匯出你在意的角色卡並保留備份。問題和建議請提交到 GitHub Issues。

CCV4 卡片格式

CCV4 是草案階段的角色卡格式，由 TOML 撰寫的小型可定址文字區塊組成，儲存在 PNG 區塊中。閱讀 CCV4 總覽，內含完整規範、提示詞組裝演算法、參考範例與線上遊樂場。
