Cardwave

適用於 Windows 和 Linux 的 AI 角色聊天應用程式與角色卡編輯器。接入你已在使用的任何 AI 服務商。你的角色卡、聊天和金鑰都留在你的電腦上。

功能

  • 角色卡。自己寫角色、生成一個，或與 AI 一起創作。
  • 依需求。選出你需要的，看看哪些角色能提供。
  • 記憶。角色記得你們聊天中發生過的事。
  • 夥伴。桌面上會和你聊天的 3D 形象。
  • 版本。角色卡的每段文字都保留先前的版本。
  • 翻譯。把角色卡譯成另一種語言，左右對照。
  • 語音。用每個角色自己的聲音朗讀回覆。
  • 自製工具。AI 在沙盒中為自己撰寫小工具。

隱私

角色卡、聊天、金鑰和設定都儲存在你電腦上的加密資料庫中。無需註冊，沒有同步，應用程式內沒有分析統計。

使用你自己的 AI

貼上一個 API 金鑰，Cardwave 就能認出它屬於誰：OpenAI、Anthropic、Google、xAI、Mistral、DeepSeek、OpenRouter、NanoGPT，以及另外 150 多家。任何相容 OpenAI 的伺服器也能用。

也可以在你自己的電腦上執行模型。把 Cardwave 指向一個存放 GGUF 檔案的資料夾，它會盡量用你的顯示卡執行。

支援的服務商

查看 Cardwave 支援的 AI 服務商清單，每家都附有其網站連結。

角色卡

Cardwave 可匯入 SillyTavern PNG 角色卡和 CCV4 角色卡。角色卡可匯出為 SillyTavern V3 或 CCV4，聊天可匯出為 SillyTavern 格式。
