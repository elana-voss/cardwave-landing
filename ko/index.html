Cardwave

Windows용 AI 캐릭터 채팅 앱 겸 카드 에디터. 이미 쓰고 있는 AI 제공사를 그대로 연결하세요. 카드, 채팅, 키는 내 컴퓨터에 그대로 남습니다.

Windows용 다운로드

할 수 있는 것

  • 캐릭터와 채팅. 답장은 쓰이는 대로 바로 나타납니다. 다시 생성하고, 편집하고, 모든 버전을 보관하고, 어느 메시지에서든 분기할 수 있습니다. 여러 캐릭터를 한 채팅에 모으면 차례로 말하거나 자기들끼리 대화를 이어 갑니다.
  • 카드 만들기와 편집. 카드 페이지가 곧 에디터이며, 모든 텍스트는 이전 초안을 보관합니다. 카드를 처음부터 쓰거나, AI의 질문에 답하면 AI가 함께 캐릭터를 써 줍니다.
  • 잘 찾아 주는 라이브러리. 단어와 의미로 검색하며, 검색 모델은 내 컴퓨터에서 실행됩니다. AI가 카드마다 태그, 한 줄 소개, 요약을 씁니다. 페르소나와 로어북은 캐릭터 바로 옆에 있습니다.
  • 기억. 20개 메시지마다 AI가 채팅의 사실과 사건을 기록하고, 캐릭터는 답하기 전에 자기가 아는 것을 떠올립니다. 채팅이나 캐릭터에게 참고할 문서를 줄 수 있습니다.
  • 음성과 그림. 메시지를 내 컴퓨터에서 소리 내어 읽으며, 캐릭터마다 고유한 목소리나 녹음으로 만든 목소리를 씁니다. 채팅에서 제공사의 이미지 모델이나 ComfyUI로 그림을 만들 수 있습니다.
  • 도구. 모델이 웹을 검색하고, 한 폴더의 파일을 다루고, 샌드박스에서 명령을 실행하게 할 수 있습니다. 모두 내가 허락한 만큼만입니다. 코딩 팀이 폴더 안의 목표를 대신 작업할 수도 있습니다.
  • 잠금과 백업. 비밀번호로 앱을 잠급니다. 백업은 보호된 파일 하나로, 이 컴퓨터나 다른 컴퓨터에서 복원됩니다.
  • 내 언어로. Cardwave는 12개 언어를 지원하며, 밝은 테마와 어두운 테마가 있습니다.

프라이버시

Cardwave는 카드, 채팅, 키, 설정을 내 컴퓨터에 저장합니다. 가입 없음, 동기화 없음, 앱 내 분석 없음. 인터넷에는 내가 요청한 일에만 연결합니다: API 키를 입력한 제공사로 가는 메시지, 내가 시작한 다운로드(검색 모델, 음성), 켜 둔 웹 도구, 그리고 GitHub에서 새 버전 확인(설정에서 끌 수 있습니다). 중간에 Cardwave 서버는 없습니다.

모델

Cardwave는 API 키를 받아 제공사와 직접 통신합니다. 키를 붙여 넣으면 Cardwave가 어느 제공사의 키인지 알려 주고, 채팅용 모델과 앱 자체의 백그라운드 작업용으로 더 저렴한 모델을 고르도록 도와줍니다. 아래에서 제공사를 고르거나 직접 추가하세요. 여러 설정을 프리셋으로 저장해 바꿔 가며 쓸 수 있습니다. Cardwave 구독은 없습니다.

  • platform.openai.com GPT- OpenAI
  • console.anthropic.com Claude - Anthropic
  • aistudio.google.com Gemini- Google
  • console.x.ai Grok - xAI
  • openrouter.ai OpenRouter- 다양한 모델
  • nano-gpt.com NanoGPT - 다양한 모델

다른 것을 쓰시나요? 직접 추가하세요. 주소를 입력해 Cardwave를 OpenAI 호환 서버로 연결하면 됩니다. 본인 컴퓨터의 로컬 모델도 가능합니다. Cardwave가 모델 목록을 가져오거나, 모델을 직접 입력합니다. 로컬 서버는 API 키가 필요 없습니다.

카드

Cardwave는 SillyTavern PNG 카드와 CCV4 카드를 '만들기'에서, 또는 라이브러리에 끌어다 놓아 가져옵니다. 카드는 SillyTavern V3나 CCV4로, 채팅은 SillyTavern의 채팅 형식으로 내보냅니다.

캐릭터 찾는 곳

Cardwave는 어디서 받은 카드든 열 수 있습니다. 다운로드해서 Cardwave로 가져올 수 있는 캐릭터 카드를 제공하는 사이트 목록을 확인하세요.

비용 추정

채팅 비용은 대화가 길어질수록 커집니다. 매 턴마다 히스토리를 다시 전송하기 때문입니다. 채팅 턴 예산 계산기는 모델별 토큰 단가로 예산이 몇 턴을 감당하는지 추정합니다.

프로젝트 범위

Cardwave는 무료이며 한 사람이 만듭니다. 있는 그대로 배포됩니다. 버그 신고와 기능 요청은 GitHub Issues로 환영합니다.

베타. Cardwave는 활발히 개발 중입니다. 캐릭터 카드는 백업해 두세요.

CCV4 카드 포맷

CCV4는 TOML로 된 작고 주소 지정 가능한 텍스트 블록을 PNG 청크에 저장하는 초안 단계의 캐릭터 카드 포맷입니다. 전체 사양, 프롬프트 조립 알고리즘, 참조 예제, 라이브 플레이그라운드가 포함된 CCV4 개요를 읽어 보세요.
