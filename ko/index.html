Cardwave

Windows용 AI 캐릭터 채팅 앱 겸 카드 에디터. 이미 쓰고 있는 AI 제공사를 그대로 연결하세요. 카드, 채팅, 키는 내 컴퓨터에 그대로 남습니다.

Windows용 다운로드

기능

  • 채팅. 한 캐릭터나 여러 캐릭터와 대화하세요. 캐릭터들은 차례로 말하거나 자기들끼리 대화를 이어 갑니다. 어느 메시지로든 돌아가 다른 길을 시도할 수 있습니다.
  • 카드. 캐릭터를 처음부터 만들거나 AI와 대화하며 만들고, 캐릭터만의 페이지에서 편집하세요.
  • 라이브러리. 이름, 태그, 내용으로 캐릭터를 찾으세요. AI가 카드에 태그를 달고 요약합니다.
  • 기억. 캐릭터는 있었던 일을 기억하고, 내가 준 문서를 참고할 수 있습니다.
  • 컴패니언. 바탕 화면의 3D 피규어가 나와 이야기하고, 답을 소리 내어 읽어 주며 곁에 있어 줍니다. 일상의 도우미로도 쓸 수 있습니다.
  • 음성. 답을 캐릭터마다 고유한 목소리로, 내 컴퓨터에서 읽어 줍니다. 타이핑 대신 받아쓰기도 됩니다.
  • 이미지. 채팅 안에서 이미지를 만드세요.
  • 도구. 모델이 웹을 검색하고, 한 폴더에서 작업하거나 명령을 실행하게 하세요. 모두 내가 허락한 만큼만 합니다.
  • 코딩 팀. 목표와 폴더를 주면 AI 에이전트 팀이 나 대신 작업합니다.
  • 로컬 모델. 키도 계정도 없이 내 컴퓨터에서 모델을 실행하세요.
  • 탭과 테마. 여러 채팅과 카드를 탭으로 열어 두세요. 라이트, 다크 또는 다섯 가지 다른 테마 중 하나.
  • 잠금과 백업. 비밀번호로 앱을 잠그고, 백업은 파일 하나입니다.
  • 휴대폰과 다른 컴퓨터. 집 네트워크에 있는 휴대폰이나 다른 컴퓨터의 브라우저에서 Cardwave를 여세요. 초기 단계로, 아직 충분히 테스트되지 않았습니다.
  • 내 언어로. Cardwave는 12개 언어를 지원합니다.

프라이버시

Cardwave는 카드, 채팅, 키, 설정을 내 컴퓨터의 암호화된 데이터베이스에 저장합니다. 가입 없음, 동기화 없음, 앱 내 분석 없음. 인터넷에는 내가 요청한 일에만 연결합니다: API 키를 입력한 제공사로 가는 메시지, 내가 시작한 다운로드(검색 모델, 음성), 켜 둔 웹 도구, 그리고 GitHub에서 새 버전 확인(설정에서 끌 수 있습니다).

내 AI 사용하기

이미 쓰고 있는 AI를 그대로 쓰세요. API 키를 붙여 넣으면 Cardwave가 어느 곳의 키인지 알아봅니다: OpenAI, Anthropic, Google, xAI, Mistral, DeepSeek, OpenRouter, NanoGPT 그리고 150곳 이상. OpenAI 호환 서버도 주소만 있으면 됩니다.

또는 내 컴퓨터에서 모델을 실행하세요: GGUF 파일이 있는 폴더를 지정하면 Cardwave가 직접 실행하며, 가능하면 그래픽 카드를 씁니다.

지원하는 제공사

Cardwave가 지원하는 AI 제공사 목록을 확인하세요. 각 사이트로 가는 링크가 있습니다.

카드

Cardwave는 SillyTavern PNG 카드와 CCV4 카드를 '만들기'에서, 또는 라이브러리에 끌어다 놓아 가져옵니다. 카드는 SillyTavern V3나 CCV4로, 채팅은 SillyTavern의 채팅 형식으로 내보냅니다.

캐릭터 찾는 곳

Cardwave는 어디서 받은 카드든 열 수 있습니다. 다운로드해서 Cardwave로 가져올 수 있는 캐릭터 카드를 제공하는 사이트 목록을 확인하세요.

비용 추정

채팅 비용은 대화가 길어질수록 커집니다. 매 턴마다 히스토리를 다시 전송하기 때문입니다. 채팅 턴 예산 계산기는 모델별 토큰 단가로 예산이 몇 턴을 감당하는지 추정합니다.

롤플레이 인기 모델

OpenRouter에서 가장 인기 있는 롤플레이 모델과 가격. 매일 업데이트.

프로젝트 범위

Cardwave는 무료이며 한 사람이 만듭니다. 있는 그대로 배포됩니다.

베타

Cardwave는 활발히 개발 중이며, 이번이 첫 공개 릴리스입니다. 업데이트가 이전 버전이 저장한 것을 유지하지 못할 수 있으니, 아끼는 카드는 내보내고 백업을 해 두세요. 버그와 바라는 점은 GitHub Issues로 보내 주세요.

CCV4 카드 포맷

CCV4는 TOML로 된 작고 주소 지정 가능한 텍스트 블록을 PNG 청크에 저장하는 초안 단계의 캐릭터 카드 포맷입니다. 전체 사양, 프롬프트 조립 알고리즘, 참조 예제, 라이브 플레이그라운드가 포함된 CCV4 개요를 읽어 보세요.
